# ВГТУ Зачётка

Приложение для просмотра оценок и расчёта стипендии студентов ВГТУ.

## Возможности

- Авторизация через официальный API ВГТУ
- Просмотр оценок по семестрам с фильтрацией
- Расчёт среднего балла и прогноз стипендии (повышенная x1.6 / x1.4, обычная x1.2, минимальная x1)
- **Симулятор оценок** — выставляй предполагаемые оценки за незакрытые предметы и сразу видь, как изменится средний балл и стипендия
- Оффлайн-режим — данные кэшируются, работает без интернета
- Уведомления о новых оценках при входе
- Обратная связь разработчику через Telegram

## Стек

- Python 3.x
- Flet (GUI)
- requests (HTTP/API)
- JSON (кэш)

## Установка
На ПК
```bash
pip install flet requests
```

На андроид просто скачать Apk из релизов, установить, при первом входе иметь подключение к интернету
