# ВГТУ Зачётка

Приложение для просмотра оценок и расчёта стипендии студентов ВГТУ. Авторизуется через официальный API университета.

## Возможности

- Авторизация через официальный API ВГТУ
- Просмотр оценок по семестрам с фильтрацией
- Расчёт среднего балла и прогноз стипендии (повышенная x1.6 / x1.4, обычная x1.2, минимальная x1)
- **Симулятор оценок** — выставь предполагаемые оценки за незакрытые предметы и сразу увидь, как изменится средний балл и стипендия
- Оффлайн-режим — данные кэшируются, работает без интернета
- Уведомления о новых оценках при входе
- Обратная связь разработчику через Telegram

## Стек

- Python 3
- [Flet](https://flet.dev) (GUI)
- requests (HTTP/API)
- JSON (локальный кэш)

## Запуск из исходников

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

## Кнопка «Обратная связь» (Telegram)

Токен бота и chat_id задаются переменными окружения (в код не хардкодятся):

```bash
export TG_BOT_TOKEN="<токен от BotFather>"
export TG_CHAT_ID="<ваш chat_id>"
```

Без них приложение работает, но отправка обратной связи отключена.

## Сборка APK

Сборка Android-версии запускается вручную через GitHub Actions (workflow **Build Zachetka APK**, `workflow_dispatch`), готовый `.apk` — в артефактах запуска.

Локально:

```bash
flet build apk --product "Зачётка"
```

Для Android просто скачайте `.apk` из релизов, установите и при первом входе дайте доступ к интернету.
